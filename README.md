# Task 1 — Data Preprocessing & Exploratory Data Analysis

## Objective
Preprocess an e-commerce sales dataset and explore sales patterns using descriptive statistics and visualizations.

## Preprocessing
- Missing-value detection and imputation
- Duplicate removal
- Numerical summary
- Categorical value handling

## EDA
- Sales by category
- Sales distribution
- Box plot
- Correlation heatmap

## Run
```bash
pip install -r requirements.txt
python preprocess_eda.py
```
